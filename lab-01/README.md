# Практика 1 · Jakarta EE

Учебное приложение с трёхслойной архитектурой, CRUD и как минимум двумя сущностями.

Условие предусматривает SQL для создания и наполнения базы, JPA, сессионные EJB и слой представления. Развёртывание выполняется средствами сервера приложений без IDE.

## Критерии по заданиям преподавателя

1. Установить и запустить GlassFish или другой сервер приложений. Открыть консоль администратора и ознакомиться с её элементами управления.
2. Подготовить реляционную СУБД. Преподаватель рекомендует PostgreSQL.
3. Выбрать предметную область и описать минимум две сущности с несколькими свойствами. Подготовить SQL-скрипт, который создаёт структуру БД и заполняет её начальными данными.
4. Представить модель в слое данных как JavaBeans и настроить отображение сущностей на таблицы средствами Jakarta Persistence (JPA).
5. Реализовать доступ к данным и их изменение через сессионные EJB.
6. Создать слой представления на выбранной технологии. Приложение должно позволять просматривать, добавлять, редактировать и удалять данные.
7. Проверить совместную работу трёх слоёв и БД. Для развёртывания использовать консоль администратора или конфигурационные файлы сервера приложений.
