# АКС. Практические работы

Каталог курсов и занятий. В каждой папке есть команды сборки, запуска и проверки.

| Работа | Что реализовано | Скриншот |
|---|---|---|
| [ПР1. Jakarta EE](lab-01/) | Каталог на GlassFish, JPA, EJB и JSP | [Каталог](docs/images/lab-01.png) |
| [ПР2. Spring](lab-02/) | Формы CRUD на Spring MVC, Hibernate и Thymeleaf | [Перенос занятия](docs/images/lab-02.png) |
| [ПР3. REST](lab-03/) | CRUD API с JSON и XML, просмотр XML через XSL | [Список из XML](docs/images/lab-03.png) |
| [ПР4. JMS](lab-04/) | Аудит изменений в PostgreSQL и уведомления через Artemis | [Письмо в Mailpit](docs/images/lab-04.png) |

Проекты собираются через Gradle Wrapper на JDK 25. Для каждой работы
используется своя база PostgreSQL. Настройки подключения приведены в README.
